# 🔔 กระดิ่งทอง มรณะ — โปรแกรมฝั่งผู้ใช้ (Client)

โปรแกรม Windows สำหรับระบบเช็คชื่อ "กระดิ่งทอง มรณะ" — เชื่อมต่อเซิร์ฟเวอร์คลาวด์บน Railway
(ฝั่งเซิร์ฟเวอร์อยู่ที่ repo [golden-bell-server](https://github.com/benzodol789-png/golden-bell-server))

- `admin.py` — โปรแกรมแอดมิน: สร้างห้อง เรียกเช็คชื่อ ดูประวัติ (บอกชื่อผู้เรียก) ดูสถิติวันนี้ของทุกคน
- `student.py` — โปรแกรมพนักงาน: เข้าห้อง รอเรียก กดยืนยันเช็คชื่อ ดูสถิติของตัวเอง และรับป้ายเตือนใกล้หมดเวลา
- `updater.py` — ระบบอัพเดทโปรแกรมในตัว (ปุ่ม "🔄 อัพเดทโปรแกรม" เช็คจาก GitHub Releases)
- `tray.py` — ไอคอนที่ถาดมุมขวาล่าง + เปิดเองตอนเปิดเครื่อง + กันเปิดโปรแกรมซ้อน (ใช้ในโปรแกรมพนักงาน)
- `assets/` — เสียงแจ้งเตือน + โลโก้ + รูปป้ายเตือน (ถูก bundle เข้า .exe)
- `tools/` — สคริปต์สร้างไฟล์ใน assets ใหม่ (เช่น `make_alert_break.py` วาดรูปป้ายเตือน)
- `tests/` — ทดสอบ E2E โปรโตคอลกับเซิร์ฟเวอร์จริง

## โปรแกรมพนักงานทำงานเบื้องหลัง + จุดเช็คชื่อของตัวเอง (v3.5.0)

- **เปิดเองตอนเปิดเครื่อง** — โปรแกรมลงทะเบียนตัวเองไว้ที่ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
  (ชื่อ `GoldenBellEmployee`, ระดับผู้ใช้ ไม่ต้องใช้สิทธิ์แอดมิน) แล้วเปิดแบบซ่อนไว้ที่ถาด (`--tray`)
  ปิด/เปิดได้ที่เมนูคลิกขวาไอคอน → "เปิดโปรแกรมเองตอนเปิดเครื่อง" (จำค่าไว้ใน prefs.json `autostart`)
- **กด ✕ = ซ่อนไว้ที่ถาดมุมขวาล่าง** โปรแกรมยังทำงานอยู่ ยังรับการเรียกเช็คชื่อ/ป้ายเตือนครบ
  คลิกไอคอนกระดิ่ง = เปิดหน้าต่าง / คลิกขวา → "ออกจากโปรแกรม" = ปิดจริง (ถามยืนยันก่อน)
- **เข้าห้องเดิมให้เอง** — จำห้องล่าสุดไว้ (prefs.json `last_room`) เปิดโปรแกรมแล้วพาเข้าห้องนั้นทันทีเมื่อห้องยังอยู่
  กด "ออกจากห้อง" เอง = ล้างค่า / เปิดแบบซ่อนแล้วเข้าห้องไม่ได้ใน 45 วินาที → โชว์หน้าต่างให้เลือกห้องเอง
- **เปิดได้ทีละตัว** — กดเปิดโปรแกรมซ้ำ = เรียกหน้าต่างของตัวที่เปิดอยู่ขึ้นมาแทน (named mutex + event ของ Windows)
- **จุดเช็คชื่อ 3 รอบของตัวเอง** แบบเดียวกับฝั่งแอดมิน — ใต้ชื่อในหน้าห้อง (วงทองล้อม = รอบตอนนี้)
  พร้อมบอกเป็นคำว่า "✅ เช็คชื่อรอบ 2 แล้ว (10:15)" / "❗ ยังไม่ได้เช็คชื่อรอบ 2 — ไปเช็คชื่อในกลุ่มด่วน"
  ตารางในห้องมีคอลัมน์ "🔔 เช็คชื่อ (รอบ N)" เหมือนของแอดมิน และไอคอนที่ถาดมีจุดแดง/เขียวบอกรอบตอนนี้
  (ข้อมูลมาจาก `members_status` ที่เซิร์ฟเวอร์ส่งให้ทั้งห้องอยู่แล้ว — ฝั่งเซิร์ฟเวอร์ไม่ต้องแก้)
- ทดสอบจาก source ได้โดยไม่ชนตัว .exe ที่เปิดใช้งานจริง (ใช้ตัวล็อกคนละชื่อ และไม่แตะค่าเปิดเครื่อง)
  ตั้ง `APPDATA` เป็นโฟลเดอร์ทดสอบเพื่อแยก prefs / ชื่อที่จำไว้ / ธีม ออกจากของจริง

## เรียกเช็คชื่อ — ไม่ตอบ / ยกเลิกเรียก (v3.4.0)

- เรียกแล้วพนักงานมีเวลากดยืนยัน **10 นาที** — ครบแล้วยังไม่กดถึงบันทึกว่า "⌛ ไม่ตอบ"
  (ตารางแอดมินนับถอยหลัง `🔔 รอยืนยัน 9:41` / ครบเวลาแล้วป๊อปอัพที่เครื่องพนักงานปิดเองและหยุดเสียง)
- กดเรียกซ้ำระหว่างรอ = ส่งเสียงเรียกอีกรอบเฉยๆ ไม่นับครั้งก่อนเป็นไม่ตอบ และไม่เริ่มนับเวลาใหม่
- พนักงานหลุดเน็ต/ออกจากห้องระหว่างรอ แล้วกลับเข้าห้องเดิมด้วยชื่อเดิมภายในเวลา → ป๊อปอัพขึ้นใหม่ เวลานับต่อจากเดิม
- ปุ่ม "✖ ยกเลิกเรียก" (แอดมิน) — ใช้ตอนกดเรียกผิด เช่น คนนั้นไปเข้าห้องน้ำ/กินข้าวอยู่:
  ไม่นับว่าไม่ตอบ, สถานะในตารางกลับไปเหมือนก่อนเรียก, ป๊อปอัพที่เครื่องพนักงานปิดเอง
  และประวัติขึ้นว่า "🚫 ยกเลิก" (ไฟล์ .zip บอกว่าใครยกเลิก เวลาไหน)
- ลบห้องระหว่างที่มีคนรอยืนยัน → บันทึกเป็น "ยกเลิก (ลบห้อง)" ไม่ใช่ไม่ตอบ
- ประวัติเรียงตามเวลากดเรียก ใหม่สุดอยู่บน
- เซิร์ฟเวอร์ตั้งเวลาได้ด้วย env `CALL_TIMEOUT` (วินาที, ค่าเริ่มต้น 600)

## ออกไปข้างนอก — ป้ายเตือนและสถิติ (v3.3.0)

ข้อมูลว่าใครออกไปกินข้าว/ปวดหนัก/ปวดน้อย มาจากระบบ check-status (บอทอ่านจากกลุ่ม Telegram)
เซิร์ฟเวอร์กระดิ่งทองเป็นตัวกลางส่งต่อให้โปรแกรม — **ไม่มีการส่งข้อความเข้ากลุ่มเลย**

- เหลือเวลาไม่ถึง 1 นาที → ฝั่งพนักงานขึ้นป้าย `alert_break.png` กลางจอ (สั่น + นับถอยหลังสด)
  พร้อมเสียงเช็คชื่อแล้วตามด้วยเสียงพูด "ใกล้หมดเวลาแล้ว กรุณากดกลับที่นั่ง" (`alert_break_voice.mp3`)
- เกินเวลาแล้ว → ป้ายเปลี่ยนเป็นสีแดงและเตือนซ้ำอีกครั้งหนึ่ง / กดกลับที่นั่งในกลุ่มแล้วป้ายเก็บเอง
- ปุ่ม "📊 สถิติของฉัน" (พนักงาน) / "📊 สถิติวันนี้" (แอดมิน) — นับเป็นวันต่อวัน ตัดรอบ 02:00 น.
- ตารางในห้องมีคอลัมน์ "📊 ออกไปวันนี้" บอกเวลารวมของแต่ละคน
- ฝั่งแอดมิน: คลิกหัวคอลัมน์ในตารางห้องเพื่อเรียง (ชื่อห้อง/จำนวนพนักงาน/แอดมิน) กดซ้ำสลับขึ้น-ลง จำค่าไว้ให้
- ตารางทุกตัว (v3.4.1): ตัวหนังสือยืด-หดตามความกว้างหน้าต่าง มีระยะขอบในช่อง และไม่ถูกตัดท้าย
  (`theme.FitTable`) — หดหน้าต่างลง ตารางหดก่อน ปุ่มกับแถบล่างยังอยู่ครบ

เซิร์ฟเวอร์: `https://goldenbell.jed89.com` (Railway, auto-deploy จาก repo ฝั่ง server)

## Build

```
py -3 -m PyInstaller เช็คชื่อ-ครู.spec --noconfirm       # → dist/กระดิ่งทองมรณะ-แอดมิน.exe
py -3 -m PyInstaller เช็คชื่อ-นักเรียน.spec --noconfirm   # → dist/กระดิ่งทองมรณะ-พนักงาน.exe
py -3 make_packages.py                                    # → .zip แจกจ่ายทั้งสองชุด
```

## ปล่อยเวอร์ชันใหม่ (ระบบอัพเดทในโปรแกรมดึงจากตรงนี้)

1. แก้โค้ด แล้วอัพเลขเวอร์ชัน `APP_VERSION` ใน `updater.py` (release.py ใช้เลขนี้ตั้งชื่อ tag)
   และ `version_admin.txt` / `version_student.txt` (เลขใน Properties ของไฟล์ .exe)
   จากนั้น commit แล้ว **push ก่อน** — `gh release create` ติด tag ที่ origin/main ตอนนั้น
2. ปิดโปรแกรมที่เปิดจาก `dist\` ก่อน แล้วรันสคริปต์ปล่อยเวอร์ชัน — build + zip + สร้าง GitHub Release ในคำสั่งเดียว:

```
py -3 release.py "สรุปว่ามีอะไรใหม่ (ผู้ใช้เห็นข้อความนี้ตอนกดอัพเดท)"
```

3. ผู้ใช้กดปุ่ม "🔄 อัพเดทโปรแกรม" ในแอพ → โปรแกรมดาวน์โหลด สลับไฟล์ และรีสตาร์ทเอง

> release.py จะอัพโหลด asset เป็นชื่อ ASCII (`golden-bell-admin.exe` / `golden-bell-employee.exe`)
> เพราะ GitHub เปลี่ยนชื่อไฟล์ภาษาไทย — โปรแกรมใช้ชื่อ ASCII นี้หาไฟล์อัพเดท
> ส่วนชื่อไฟล์บนเครื่องผู้ใช้ยังเป็นภาษาไทยเหมือนเดิม
